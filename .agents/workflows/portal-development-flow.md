---
description: Flujo estandarizado para el desarrollo, compilación y despliegue de funcionalidades en Portal Necoclí 2.0.
---

1. Analizar el requerimiento técnico y estructurar las interfaces y tipos de datos en TypeScript dentro de la carpeta correspondiente, asegurando tipado estricto (cero 'any').
2. Implementar la lógica del servidor, rutas de API y Server Actions bajo la arquitectura de Next.js App Router.
3. Desarrollar la interfaz visual en el frontend utilizando componentes reutilizables con Tailwind CSS y componentes de Shadcn UI.
4. Validar el proyecto localmente ejecutando los comandos 'npm run build' y 'npx tsc'. Corregir de forma autónoma cualquier error de compilación o linter.
5. Gestionar el control de versiones creando la rama correspondiente (feature/), confirmar los cambios (commit) y subirlos al repositorio remoto en GitHub.
6. Redactar y generar el Pull Request (PR) correspondiente con un título claro y una descripción técnica detallada del trabajo realizado.
